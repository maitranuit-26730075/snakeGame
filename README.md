# SS004.9 - Bài tập làm việc nhóm với Git

## Đề tài
**Lập trình game Snake**

Bài tập thực hành làm việc nhóm 3 sinh viên, sử dụng Git/GitHub để quản lý mã nguồn, làm việc trên các branch riêng, tạo Pull Request và merge code.

## Thành viên nhóm

| STT | MSSV | Họ và tên |
|---|---|---|
| 1 | 26730075 | Trương Quách Mai Trân |
| 2 | 26730049 | Hoàng Thảo My |
| 3 | 26730067 | Phùng Minh Thư |

## Phân công

- **Trương Quách Mai Trân** - Nhóm trưởng
  - Khởi tạo code nền của game Snake.
  - Tạo và quản lý repository GitHub.
  - Phân chia công việc, review Pull Request và merge code.
  - Kiểm tra và tích hợp phiên bản cuối.

- **Hoàng Thảo My**
  - Phụ trách chức năng vẽ khung trò chơi.
  - Kiểm tra tọa độ và hiển thị khung trên Windows Console.
  - Làm việc trên branch riêng và tạo Pull Request sau khi hoàn thành.
  - Hỗ trợ kiểm thử giao diện và bố cục game sau khi merge.

- **Phùng Minh Thư**
  - Phụ trách chức năng sinh mồi ngẫu nhiên.
  - Xử lý sự kiện rắn ăn mồi và tăng chiều dài.
  - Làm việc trên branch riêng và tạo Pull Request sau khi hoàn thành.
  - Hỗ trợ kiểm thử logic ăn mồi và hoạt động của game sau khi merge.

## Branch phụ trách

| Thành viên | Branch | Chức năng |
|---|---|---|
| Trân | `main` | Code nền, quản lý và tích hợp |
| My | `Ve-Khung` | Vẽ khung trò chơi |
| Thư | `An-Moi` | Sinh mồi và xử lý ăn mồi |
